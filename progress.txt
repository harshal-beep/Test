## Codebase Patterns
- Dashboard source lives in `src/dashboard/` — all npm commands run from there
- Tailwind v4 with `@tailwindcss/vite` plugin — custom tokens defined in `@theme` block in `src/index.css`
- Pucho brand colors available as Tailwind utilities: `text-pucho-violet`, `bg-sidebar-bg`, `text-violet-blossom`, etc.
- Font families: `font-heading` (Anek Latin), `font-body` (Lato), `font-mono` (Chivo Mono)
- Radius tokens: `rounded-card` (12px), `rounded-button` (8px), `rounded-input` (6px)
- Layout: Sidebar (240px) + main content area with Footer
- Routing via react-router-dom with Layout wrapper
- TypeScript strict mode enabled
